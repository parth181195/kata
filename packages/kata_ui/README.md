# kata_ui

Monochrome, Nothing-OS-flavoured Flutter widget kit: tokens (`KataColors`, `KataRadii`, `KataType`), `KataTheme` (dark/light with a `KataPalette` ThemeExtension), and the widgets used by the Kata app — pill buttons, status pills, chips, sheets, spec grid + ruler, swatch bars, slot cards, checklist steps, dot-matrix progress, frame slots, bottom nav.

Fonts bundled (OFL): Doto, Inter, JetBrains Mono. MIT.
