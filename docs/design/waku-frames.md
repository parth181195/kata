# Waku — curated frame gallery: research & roadmap

> **Status (2026-08-26):** the frames described here — polaroid, poster, words —
> were retired. This file survives as the reference inventory that fed
> `waku-spec.md`; the built objects are the stamp, the 35mm negative strip and
> the archive label card, each an authored object with a rolled surface.

Mood source: Parth's Pinterest board ("kata") — analog print ephemera on paper.
Palette law: cream/black + ONE hard red (occasionally mustard); matte paper grain
everywhere; mono/typewriter for data, script for emotion, condensed display for
statements, small Japanese text as garnish. Nothing glossy, no wooden frames, no
pastel templates: every frame is a printed object.

## Shared kit (build once; every frame draws from it)
- Paper-grain cream ground (compose/grain shader on surfaces)
- Hairline black rules · mono data lines · script accent font
- One red element per frame (stamp ink / grease pencil / timestamp / hanko)
- Procedural barcode generator (Code-39-style bars from caption text)
- Draggable fastener/annotation overlays usable on ANY frame: washi tape,
  paperclip, push pin, staple, scribbled arrows, hanko stamp, vertical Japanese
  caption. (The board treats these as elements, not frames.)

## Ranked shortlist
1. **Postage stamp + postmark** — photo inside perforated stamp edge on a
   contrasting backdrop. Perf 11–14 gauge → scallops ~0.8–1mm radius at
   ~1.5–1.8mm pitch, irregular torn depth; thin inner white margin; corner
   denomination + country line. Circular date stamp (~22–25mm, arced place
   text) + 5–7 wavy killer bars, ink noise-broken, MUST overlap stamp edge.
   Draggable: postmark, stamp. MEDIUM.
2. **Archive/museum label card** — photo mounted on paper + maroon tombstone
   card: artist / italic title / date / medium (auto: camera + film sim +
   recipe) / accession number + generated barcode. Left-aligned strict
   hierarchy. EASY — best authenticity-per-effort.
3. **35mm negative strip, real edge print** — rounded-rect sprockets 2×2.8mm
   at 4.75mm pitch (round holes = fake); edge print above sprockets (recipe
   name as stock: "FUJI CLASSIC NEG 400"), frame numbers 12/12A with arrows,
   DX latent barcode below opposite row, greenish-white ink, slight bloom.
   Script overlay slot in mustard, draggable/rotatable. EASY-MEDIUM.
4. **Contact sheet + grease-pencil circle** — grid of small 3:2 frames; the
   select circled in waxy red china-marker (noise-perturbed ellipse, variable
   width, occasional double pass); corner mono file-number stamp. Signature
   interaction: DRAG the circle to choose your select. MEDIUM.
5. **Postcard back** — divided back: "POST CARD" spaced caps, vertical hairline
   divider, ruled address lines + PLACE STAMP HERE box (photo can fill the box
   — composes with #1), script message left, red postmark crossing the divider.
   EASY-MEDIUM.
6. **Ticket / receipt** — Edmondson ticket 30.5×57mm, serial, punch hole; or
   thermal receipt on black: photo as logo block, recipe as mono line items
   ("CLASSIC NEG ..... 1 / GRAIN: WEAK"), dashed rules, barcode, torn edges,
   thermal fade. EASY.
7. **Riso/halftone editorial poster** — the photo itself run through a 1–2
   spot-colour halftone screen (red+black) with 1–3mm misregistration; corner
   numeral, vertical red display word, small quote line. Needs a halftone
   fragment shader. MEDIUM-HARD — the gallery's showpiece.
8. **Photo-dump timestamp grid** — checkerboard of B&W photo cells and white
   cells with red mono timestamps (EXIF-fed) or a split giant year numeral.
   Tap-to-swap cells. Alt style: orange 7-segment quartz-date digits. EASY.

## Shelved (numbers captured for later)
- Instax Mini 54×86 (image 46×62, chin ~18–19) / Square 72×85.6 (62×62) /
  Wide 108×86 (99×62) — mainstream wave 2; no board presence.
- Polaroid 600/SX-70 reference vs our shipped frame: total 107.5×88.5,
  image 79×76.8 (not quite square), sides ~4.8, chin ~20–21.
- FP-100C peel-apart (heritage drop), 6×6 Hasselblad rebate (needs square
  crop), museum overmat (absorbed into #2), magazine layout (too
  photo-dependent).

Trend check 2024–26: EXIF borders are the mainstream default; film-strip
templates are mass-market but sloppy (accuracy is our differentiator);
photo-dump grids dominate Pinterest; Y2K date stamps rising; Xiaohongshu plog
likes clean margins + small CJK captions. The board's mood is ahead of these
currents, not against them.
